# Awtybots 5829 team app (prototype)

One app for FRC Team 5829: hours check-in, tasks, scouting, inventory and orders, with student, parent and mentor views.

- `index.html`: current prototype (design direction A: black, gold and green). Open it in a browser; on a computer it shows a phone frame with a role switcher.
- `prototypes/`: earlier versions, kept for comparison.

Sample data only. Nothing is saved yet.
